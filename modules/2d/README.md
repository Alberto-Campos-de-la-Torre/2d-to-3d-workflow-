# Modulo 2D

Generacion Qwen, referencias, prompts con IA, juez de imagen, correccion iterativa,
observaciones del usuario y galeria con borrado. No importa manifold3d ni el motor 3D.

Instalar: `python instalar.py --comfyui <carpeta-ComfyUI> --perfil 2d`.
Instala sus requisitos usando el Python de ComfyUI y abre `/exo/estudio`.
Los pesos de Qwen, VAE y codificador se descargan aparte (consulta REQUISITOS.md).
Exporta PNG. Puede preparar imagenes para 3D sin instalar el modulo 3D.
